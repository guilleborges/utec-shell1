# IO Redirections and Filters

This project contains Bash scripts to practice input/output redirections and shell filters.

## Tasks

### 0-hello_world
Prints "Hello, World" followed by a new line.

### 1-confused_smiley
Prints a confused smiley: "(Ôo)'

### 2-hellofile
Displays the contents of the /etc/passwd file.
### 3-twofiles
Displays the contents of /etc/passwd and /etc/hosts.
